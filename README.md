# Schedule App Demo

A mobile-friendly demo of a shift schedule viewer for hourly workers, built as a single dependency-free HTML file. Just open `index.html` in any browser, on a phone or computer. No install, no server.

## What it does

- Shows the next upcoming shift highlighted at the top
- Lists the full week of shifts with day, time, site, and role
- Filters shifts by day
- A "Request change" button marks a shift as a change request (demo only, it sends nothing anywhere)

## Sample data

All shifts are made-up examples. This demo is not connected to any company system and uses no real employee data or company branding.

## How to run

Open `index.html` in any browser. That is all.
